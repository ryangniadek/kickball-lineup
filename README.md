# Kickball lineup board

Open `index.html` in a browser. No installation or account is needed. The roster and lineups save in this browser on this device.

Use **Export** in the header to download a JSON backup of the roster, kicking order, both defenses, and field rotations. Use **Import** to restore that file in this or another browser. Import replaces the current lineup, and **Undo import** restores the previous one. Keep the JSON file if you want a portable backup.

- Add your players and mark who is playing tonight.
- Drag a player onto a field spot, or tap the player and then the spot. Dragging an occupied player onto another spot swaps them.
- Set both defensive configurations. The right-side rover counts as the fourth outfielder and should remain in the outfield until the kick.
- In **Field rotations**, add a group by choosing one or more occupied spots, then choose players from the bench. The players already in those spots start inning 1. A one-spot group with two players alternates each inning; a two-spot group with three players keeps two on the field and rotates one to the bench. Groups are configured separately for each defense.
- Use **View inning** to preview innings 1 through 7. Return to inning 1 to edit the starting field. The board checks the fielding rules in every generated inning.
- Drag players into the kicking order. Use the up and down buttons for precise adjustments.
- When more than two men are available per woman, the board automatically switches to separate men's and women's rotations. Drag within each rotation, then review the generated kick preview. It starts man, woman, man and continues with two men between women. Each rotation loops independently, so women can repeat before every man has kicked. Read the numbered preview down each column before moving right.
- The board checks both defenses and the entire repeating kicking order. Printing is enabled only when all three checks pass.
- **Print ready lineup** creates one landscape page with both starting defenses and the kicking order. Players rotating in from the bench appear directly beneath each field spot they share. A short rotation cycle sits below each field, along with any players who are available but not assigned to a field rotation. When separate men's and women's kicking rotations are needed, the page also lists the first 30 kicks in their actual sequence. Read numbered print columns from top to bottom.

Rules source: https://www.trisportsnc.com/_files/ugd/a303f8_8175c2f662cb451a820b0e9925bddfe0.pdf
